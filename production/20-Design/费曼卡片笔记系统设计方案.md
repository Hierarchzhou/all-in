# 费曼卡片笔记系统设计方案
> 设计日期：2025-09-25
> 版本：v1.0
> 状态：概念设计

## 🎯 设计目标

基于认知迭代的深度反思，设计一个**聚焦生产而非管理**的个人知识工作系统。

### 核心原则
1. **生产优先**：时间投入创造价值而非信息整理
2. **标签导向**：用标签组织而非文件夹层级
3. **费曼验证**：通过教授来验证理解深度
4. **习惯适配**：系统适应个人工作流

## 🧠 费曼卡片核心机制

### 学习循环
```
📥 输入阶段 → 🤔 理解阶段 → ✍️ 重写阶段 → 📤 输出阶段 → 🔄 验证阶段
     ↓            ↓            ↓            ↓            ↓
  原始信息      提取概念      简化表达      创造内容      获得反馈
```

### 卡片结构设计
```markdown
# [卡片标题]
标签: #主题 #类型 #状态

## 核心概念
[用自己的话解释核心概念]

## 简化表达
[如何向12岁小孩解释这个概念]

## 实际应用
[这个概念在实际中如何应用]

## 关联思考
[与其他概念的连接]

## 输出计划
[如何基于这个概念创造内容]
```

## 🏷️ 标签体系设计

### 主题标签
- `#认知` - 认知科学、学习方法
- `#效率` - 生产效率、工具使用
- `#思维` - 思维模型、决策框架
- `#创作` - 内容创作、表达技巧

### 类型标签
- `#概念卡` - 核心概念解释
- `#方法卡` - 具体方法论
- `#案例卡` - 实际应用案例
- `#反思卡` - 个人思考总结

### 状态标签
- `#输入中` - 正在学习理解
- `#重写中` - 正在简化表达
- `#输出中` - 正在创造内容
- `#已验证` - 已通过教授验证

## 📁 文件组织方案

### 目录结构
```
workspace/
├── cards/              # 费曼卡片库
│   ├── inbox/         # 输入暂存区
│   ├── processing/    # 处理中卡片
│   ├── output/        # 可输出卡片
│   └── archive/       # 已归档卡片
├── templates/         # 卡片模板
└── tools/            # 辅助工具
```

### 命名规范
- 卡片文件: `YYYY-MM-DD-主题关键词.md`
- 标签使用: 英文简洁标签，便于检索
- 链接引用: `[[卡片标题]]` 格式

## 🔄 工作流程设计

### 日常流程
1. **晨间输入**（15分钟）
   - 收集新信息到inbox
   - 快速标记主题标签

2. **午间处理**（30分钟）
   - 将inbox内容转化为费曼卡片
   - 用自己的话重新表达概念

3. **晚间输出**（20分钟）
   - 基于卡片创造内容
   - 分享到社交平台获得验证

### 周期性回顾
- **每周**：回顾处理中卡片，推进到输出阶段
- **每月**：评估输出质量，调整标签体系
- **每季度**：系统性梳理知识网络

## 🛠️ 技术实现方案

### 工具选择
**推荐组合：Obsidian + 标签插件**
- 原因：轻量级、支持标签、双链笔记
- 优势：符合费曼卡片的网状知识结构

### 替代方案
1. **Notion**: 数据库功能强大，适合结构化管理
2. **Logseq**: 块编辑器，适合碎片化思考
3. **简单文本**: 最轻量，避免工具复杂性

## 📊 效果评估指标

### 生产力指标
- **输出频率**：每周创造内容数量
- **质量深度**：获得的有效反馈比例
- **理解巩固**：能够教授的概念数量

### 系统健康度
- **处理效率**：从输入到输出的平均周期
- **标签使用**：标签的实际检索频率
- **系统维护**：每周管理时间占比（目标<20%）

# 工作台文件系统愿景
- 目标：打造一个可承载所有工作流的文件系统，支撑探索、设计、生产、复盘的完整闭环。
- 核心原则：
  1. 精益迭代：所有产出按照 Discover→Design→Build→Launch→Measure→Learn 的生命周期流转。
  2. 目标导向：每条路径围绕具体用户目标或业务目标组织。
  3. 集成协同：同一项目在 `production/30-Build` 内形成“项目空间”，包含问题、方案、MVP、指标等子目录。
  4. 可扩展：引入新项目或主题时，通过复制目录模板快速落地。
- 当前实践案例：
  - `production/30-Build/精益创业实战项目`，示范精益创业实践的目录结构。
- 限制意识：工作场景差异巨大，不同项目的文件系统诉求各异，因此当前结构强调通用原则与可配置模板，而非追求单一“万能”设计。

# 🏗️ All-in 新架构说明

*更新时间：2025-09-22*

## 📂 新目录结构说明

### 🤖 AI系统/
人工智能相关的所有功能模块

- **工作台/** - AI工作台核心引擎
  - `core_engine.py` - 核心调度引擎
  - `input_adapter.py` - 输入适配器
  - `preprocessor.py` - 预处理器

- **智能体/** - 各种AI角色和代理
  - `transparent_dispatcher.py` - 透明中转台
  - `agent_scheduler_demo.py` - 代理调度示例

- **工具箱/** - 实用工具集合
  - 文档转换工具（Word→MD、HTML生成等）
  - 内容处理工具

- **配置/** - 系统配置文件

### 📝 决策日志/
记录所有重要决策，便于复盘

- **架构决策/** - 技术架构相关决策
- **功能决策/** - 功能设计相关决策
- **复盘记录/** - 定期复盘总结
- **决策模板.md** - 标准化决策记录模板

### 🎯 项目管理/
项目进度和任务管理

- **任务清单/** - TODO列表和任务分解
- **进度记录/** - 项目进展记录
- **复盘总结/** - 阶段性总结

### 📔 个人空间/
个人数据和私密内容

- **日记/** - 个人日记
- **咨询档案/** - 咨询记录
- **待办事项/** - 个人待办

### 💬 对话记录/
与AI的对话历史，用于复盘学习

- 按年月组织
- 每次重要对话生成独立文档
- 包含决策、洞察和行动项

### 📋 系统文档/
项目元信息和文档

- README.md - 项目说明
- CHANGELOG.md - 更新日志
- 架构文档等

## 💡 使用建议

1. **新内容直接使用新结构**
   - 新的AI功能放入 AI系统/
   - 新的决策记录放入 决策日志/
   - 新的任务计划放入 项目管理/

2. **旧内容逐步迁移**
   - 不急于一次性迁移所有内容
   - 按需迁移，保持Git历史

3. **保持简单原则**
   - 不过度分类
   - 文件夹层级不超过3层
   - 命名清晰直观

## 🎯 核心价值

- **信息集中**：所有信息在一个仓库
- **决策可追踪**：通过Git和决策日志追踪
- **知识沉淀**：对话记录和复盘总结
- **持续进化**：每次使用都是优化

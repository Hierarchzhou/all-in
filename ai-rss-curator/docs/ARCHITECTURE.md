## 核心组件

### 1. RSSHub (内容聚合层)

**功能**: 将任何网站转换为RSS源

- **官方源**: 300+ 预置规则,覆盖主流网站
- **自定义源**: 支持自定义爬虫规则
- **缓存机制**: Redis缓存,减少重复请求
- **反爬虫**: 支持代理、Cookie、User-Agent等

**技术栈**:
- Node.js
- Redis (缓存)
- Puppeteer (动态网站)

**端口**: 1200

### 2. Miniflux (RSS阅读器 + 数据管理)

**功能**: RSS订阅管理和阅读

- **订阅管理**: 支持RSS/Atom格式
- **自动更新**: 定期拉取新内容
- **内容解析**: 支持全文抓取
- **用户系统**: 多用户、权限管理
- **RESTful API**: 完整的API接口
- **阅读体验**: 响应式设计、移动端友好

**技术栈**:
- Go语言
- PostgreSQL (数据存储)
- RESTful API

**端口**: 8080

**API文档**: https://miniflux.app/docs/api.html

### 3. PostgreSQL (数据存储)

**存储内容**:
- 用户账号和设置
- RSS订阅源
- 文章内容和元数据
- 阅读状态和收藏

**优化**:
- 索引优化 (标题、内容、时间)
- 定期清理旧数据
- 备份策略

### 4. Redis (缓存层)

**用途**:
- RSSHub请求缓存
- API响应缓存
- 限流控制
- 任务队列 (可选)

### 5. AI处理器 (rss_ai_processor.py)

**核心功能**: 智能内容分析和处理

#### 5.1 ConfigManager (配置管理)
- 加载 config.yaml
- 环境变量支持
- 默认配置fallback

#### 5.2 MinifluxClient (API客户端)
- 获取未读文章
- 获取指定时间范围文章
- 更新文章状态
- 标记收藏/已读

#### 5.3 AIAnalyzer (AI分析器)
- **支持多种AI模型**:
  - OpenAI (GPT-4, GPT-4-mini)
  - Anthropic (Claude)
  - Ollama (本地部署)

- **分析维度**:
  - 内容质量评分 (0-1)
  - 主题分类
  - 关键词提取
  - 情感分析
  - 推荐判断
  - 摘要生成

#### 5.4 RSSAIProcessor (主处理器)
- 定时任务调度
- 批量处理
- 过滤规则应用
- 结果持久化

## 数据流

### 1. 内容采集流程

```
原始网站 → RSSHub转换 → RSS源 → Miniflux订阅 → PostgreSQL存储
```

### 2. AI处理流程

```
1. 定时触发 (每5分钟)
   ↓
2. 从Miniflux获取待处理文章
   ↓
3. 批量送入AI分析器
   ↓
4. AI模型分析 (并发处理)
   ├─ 质量评分
   ├─ 主题分类
   ├─ 关键词提取
   ├─ 摘要生成
   └─ 推荐判断
   ↓
5. 应用过滤规则
   ├─ 质量阈值过滤
   ├─ 类别过滤
   ├─ 关键词过滤
   └─ 排除规则
   ↓
6. 更新文章状态
   ├─ 高质量 → 自动收藏
   ├─ 低质量 → 标记已读
   └─ 添加标签/分类
   ↓
7. 记录日志和统计
```

### 3. 用户交互流程

```
用户 → Miniflux Web界面 → 查看AI处理结果
     ↓
     阅读、收藏、分享
     ↓
     反馈数据 → 优化AI模型 (未来功能)
```

## 技术选型理由

### 为什么选择Miniflux?
- ✅ 轻量级,资源占用小
- ✅ 完整的RESTful API
- ✅ 活跃维护,安全可靠
- ✅ 支持多种数据库
- ✅ 优秀的阅读体验

### 为什么选择RSSHub?
- ✅ 300+预置规则
- ✅ 社区活跃
- ✅ 支持自定义
- ✅ 反爬虫能力强

### 为什么选择Python?
- ✅ 丰富的AI库
- ✅ 快速开发
- ✅ 易于维护
- ✅ 社区支持

### 为什么选择Docker?
- ✅ 一键部署
- ✅ 环境隔离
- ✅ 易于扩展
- ✅ 跨平台兼容

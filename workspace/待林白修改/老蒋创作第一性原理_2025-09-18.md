# 老蒋创作第一性原理分析

## 一、老蒋创作的核心公式

**老蒋创作第一性原理 = 开门见山给价值 × 具体场景论证 × 预设反驳辩证 × 层层递进深化**

## 二、典型文案结构模型

### 1. 开篇三板斧（0-30秒）

#### 模式A：直接表态度
```
"最近呢有几个热搜闹剧看得很恶心"
"我先直接在一上来说，我的态度就是..."
```

#### 模式B：抛出核心概念
```
"很多人可能都听过一个词叫不可能三角"
"它指的是..."
```

#### 模式C：设定时间轴
```
"那么未来的一个多月的时间里，我可能会聊3~5期..."
"AI现在在是一个什么样的阶段呢"
```

### 2. 价值预告（给观众留下的理由）
- "这很有可能是你全网能够找到的最深的关于不可能三角的一些拆解"
- "有百害而无一利的"
- "那我从几个方面来说一下"

### 3. 具体化论证三连
1. **举例子**："拿手机来举例"、"比如说农夫山泉的那个茶派"
2. **列现象**："一个手机它是没有办法同时做到..."
3. **推导结论**："那么必然它这个手机就不可能很小巧"

### 4. 预设反驳模式
```
提出观点 → 预判质疑 → 提前回应 → 强化论点

例：
"今天不发，明天发行吗？也不行"
"1935年的3月11号..."
"3月12号呢就更不行了"
```

### 5. 层次递进结构
- 第一层：现象描述
- 第二层：本质挖掘
- 第三层：深度思考
- 最终：给出启示

## 三、论证模式特征

### 1. 辩证思维模式
- 不是简单的对错判断
- 承认复杂性："这三个要素之间是存在矛盾的"
- 多角度分析：从手机、交通、视频博主多个维度论证

### 2. 反诘设问法
- "那请问如果我真的发了个和日本有关的视频，我怎么自证清白呢？"
- "怎么说呢？"
- "为什么？"

### 3. 荒谬归谬法
- "他是因为太荒谬，以至于很难反驳"
- 把对方逻辑推到极致，暴露其荒谬性

## 四、语言风格特征

### 1. 口语化但不失严谨
- "我去"、"搞臭你"（口语化）
- "这种非常牵强附会的非常阴谋论的攻击"（严谨表达）

### 2. 短句+长句结合
- 短句制造节奏："也不行"、"为什么"
- 长句完整论述："是少数坏人利用多数蠢人的廉价而盲目的正义感来实施的"

### 3. 情绪克制但立场鲜明
- 有态度但不谩骂
- 有批判但给理由
- 有愤怒但讲逻辑

## 五、需要剔除的非典型风格

### 非典型作品特征：
1. **vlog类**："朋友们，我现在在咱们河南郑州" - 缺乏观点输出
2. **个人分享类**："5月老蒋书影音报告" - 过于个人化
3. **纯娱乐类**："他们听完抓耳挠腮" - 缺乏深度分析

### 典型vs非典型对比：
| 要素 | 典型老蒋 | 非典型 |
|-----|---------|--------|
| 开场 | 直接给观点/概念 | 闲聊/场景描述 |
| 结构 | 清晰的123 | 散漫随意 |
| 论证 | 具体例子+逻辑推导 | 个人感受 |
| 价值 | 认知提升/观点输出 | 娱乐消遣 |

## 六、模仿老蒋的核心要点

### 1. 必须做到：
- **开门见山**：30秒内必须亮出核心观点
- **价值前置**：告诉观众为什么要看
- **具体论证**：用具体例子不讲空话
- **预设反驳**：想到反方会怎么说
- **层层深入**：不能停留在表面

### 2. 必须避免：
- 冗长铺垫
- 纯情绪输出
- 空洞说教
- 单一视角
- 没有结构

### 3. 黄金句式：
- "我先直接说..."
- "那我从几个方面来说..."
- "这里有个问题..."
- "你可能会说...但是..."
- "第一层...第二层..."
- "本质上是..."

## 七、实操创作模板

```
【开场】（10秒）
大家好，[直接抛出现象/问题/观点]

【价值预告】（10秒）
这期视频我会[具体会讲什么]，可能是[价值点]

【主体论证】（3-5分钟）
第一点/第一层：[现象] + [具体例子] + [为什么]
第二点/第二层：[深入] + [反驳预设] + [再论证]
第三点/第三层：[本质] + [推导] + [结论]

【收尾升华】（30秒）
所以本质上，[核心洞察]
这给我们的启示是，[实用价值]
```

## 八、老蒋风格检验清单

写完文案后，用这个清单自检：

☐ 开头30秒有明确观点吗？
☐ 有预告这个视频的价值吗？
☐ 有至少3个具体例子吗？
☐ 有预设并回应反驳吗？
☐ 有层层递进的结构吗？
☐ 语言够口语化吗？
☐ 逻辑够严密吗？
☐ 有情绪但克制吗？
☐ 最后有升华到本质吗？

如果有超过3个"否"，这就不是典型的老蒋风格。
